Utilities module to manipulate bytes.

Re-exported from cubecl-environment, which owns the type: this crate depends on it, so the lower layers could not otherwise use Bytes. Byte buffers with allocation properties, zero-copy views and optional memory-mapped backing. The type to use for byte payloads, never Vec<u8>.
