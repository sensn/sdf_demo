Expand description

The graphics API a WgpuDevice comes up on, which also settles the shader compiler it is fed: SPIR-V on Vulkan, MSL on Metal, WGSL elsewhere.

Auto leaves the choice to the runtime, which tries what this machine offers in the order it would want. Naming one instead pins it: the device is only reachable on that API, and stays that device wherever its id travels.
