A device of any runtime, and the runtime it belongs to. A device of any runtime, and the runtime it belongs to.

Each runtime keeps its own device type — a value, nothing more, and cubecl-runtime owns them all. This module puts one enum over them, so a caller names a device without naming a runtime, and turns that device into a Client. Every variant is there whether or not the build links the runtime, which is what keeps a stored id meaning the same thing everywhere; reaching for a client of a runtime this build left out is what fails.
