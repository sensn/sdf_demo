Trait AsMutExpand 

Source 
pub trait AsMutExpand<T = Self>
where
    T: ?Sized,
{
    // Required method
    fn __expand_ref_mut_method(&mut self, scope: &Scope) -> &mut T;

    // Provided method
    fn __expand_as_mut_method(&mut self, scope: &Scope) -> &mut T { ... }
}
Expand description

Expand version of AsMut. The Self version must be implemented by all ExpandTypes, since CubeCL also uses it to implement &mut x.
