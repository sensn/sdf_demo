Trait RegistryQuery 

Source 
pub trait RegistryQuery<K>: Into<K> { }
Expand description

To find an item from the registry, the query must be able to be translated to the actual key type.

§Example

If you use u32 as key that may become crate::frontend::NativeExpand<u32> during the expansion, both types need to implement RegistryQuery.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
