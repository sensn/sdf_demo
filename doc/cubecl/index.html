CubeCL: the language, the launch API, and the runtimes.

A kernel library depends on this crate with no runtime feature on and compiles against no runtime at all. A binary, a benchmark or a test suite turns on the features for the runtimes it wants to link, and then a Device hands back the Client to launch on — [Device::default] for the most capable runtime in the build, or a named variant for a particular one.

let client = cubecl::Device::default().client();
