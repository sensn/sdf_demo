Expand description

Describes operations that can access a sub-element of a destructurable value.

Required Methods§

Source

fn can_rewire( &self, ctx: &Context, value: &DestructurableValueSlot, used_indices: &mut SmallSet<Box<dyn Attribute>, 8>, must_be_safely_used: &mut Vec<ValueSlot>, ) -> bool

For a given destructurable value, returns whether this operation can rewire its uses of the value to use the values generated after destructuring. This may involve creating new operations.

This method must also register the indices it will access within the used_indices set. If the accessor generates new values mapping to subelements, they must be registered in must_be_safely_used to ensure they are used in a safe manner.

No IR mutation is allowed in this method.

Source

fn rewire( &self, ctx: &mut Context, value: &DestructurableValueSlot, subvalues: &HMap<Box<dyn Attribute>, ValueSlot>, rewriter: &mut IRRewriter<Recorder>, ) -> DeletionKind

Rewires the use of a slot to the generated subvalues, without deleting any operation. Returns whether the accessor should be deleted.

Deletion of operations is not allowed, only the accessor can be scheduled for deletion by returning the appropriate value.
