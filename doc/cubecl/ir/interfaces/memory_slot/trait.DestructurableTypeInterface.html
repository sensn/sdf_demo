Expand description

Describes a type that can be broken down into indexable sub-element types.

Required Methods§

Source

fn subelement_index_map( &self, ctx: &Context, ) -> Option<HMap<Box<dyn Attribute>, TypeHandle>>

Destructures the type into subelements into a map of indices to types of subelements. Returns nothing if the type cannot be destructured.

Source

fn type_at_index(&self, ctx: &Context, index: &Box<dyn Attribute>) -> TypeHandle

Indicates which type is held at the provided index, returning None if no type could be computed. While this can return information even when the type cannot be completely destructured, it must be coherent with the types returned by subelement_index_map when they exist.
