fn ensure_only_safe_accesses( &self, ctx: &Context, value: &ValueSlot, must_be_safely_used: &mut Vec<ValueSlot>, ) -> Result<(), ()>

Returns whether all accesses in this operation to the provided value are done in a safe manner. To be safe, the access must only access the value inside the bounds that its type implies.

If the safety of the accesses depends on the safety of the accesses to further value, the result of this method will be conditioned to the safety of the accesses to the value added by this method to must_be_safely_used.

No IR mutation is allowed in this method.
