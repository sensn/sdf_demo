Required Methods§

fn minimum_scope(&self, ctx: &Context) -> SyncScope

Synchronizes at least at this scope. Should be used for optimizations where smaller scopes are more conservative (i.e. marking shared memory as unused).

Source

fn maximum_scope(&self, ctx: &Context) -> SyncScope

Synchronizes at most at this scope. Should be used for optimizations where larger scopes are more conservative (i.e. making memory writes visible).
