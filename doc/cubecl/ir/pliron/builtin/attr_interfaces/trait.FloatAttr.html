Expand description

Attributes that represent a floating point value.

This trait provides operations on floating point values from the DynFloat trait.

The build_* methods can be used to construct a new FloatAttr with the same type as the argument. This can be useful when doing folding optimizations, where we have some dyn instance and want to build another one of the same type but with a different value. The self argument is ignored in these methods. In the absense of of an object (but when the concrete type is known), then the static (Self: Sized) methods on the Float trait can be used instead.
