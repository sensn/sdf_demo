Module given_names 

Source
Expand description

Utilities for attaching / retrieving given names for Operation results and BasicBlock arguments.

The names themselves are stored as GivenNamesAttr on the attribute dict of an Operation/BasicBlock with key ATTR_KEY_GIVEN_NAMES.
