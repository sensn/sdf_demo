Expand description

Interface for operations whose operands are grouped into segments.

In the case of variadic operands, sometimes it makes sense to group contiguous operands together into a segment. This interface aids doing that. MLIR achieves this by having ODS (tablegen)’ AttrSizedOperandSegments generate getODSOperands() based on the operandSegmentSizes attribute.
