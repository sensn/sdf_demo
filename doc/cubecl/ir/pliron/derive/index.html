CloneAttributeIntoContext
Implement CloneAttributeIntoContext for an Attribute by delegating to its own CloneIntoContext impl and boxing the result.
CloneIntoContext
Implement CloneIntoContext for a struct or enum, assuming every field’s type already implements it. For an enum, the matched variant is reconstructed with its (cloned) fields.
CloneTypeIntoContext
Implement CloneTypeIntoContext for a Type by delegating to its own CloneIntoContext impl, then re-interning the clone into dst_ctx.
StableHash
Implement StableHash for a struct or enum, assuming every field’s type already implements it. For an enum, the matched variant’s discriminant is also mixed into the hash.
