Expand description

Parse from parser, ignoring whitespace(s) before and after.

Warning: Do not use this inside inside combine::optional or inside repeating combiners, such as combine::many. After successfully parsing one instance, if spaces are consumed to parse the next one, but the next one doesn’t exist, it is treated as a failure that consumed some input. This messes things up. So spaces must be consumed after a successfull parse, and not prior to an upcoming one. A possibly right way to, for example, parse a comma separated list of Identifiers:

     let ids = spaces().with
               (combine::sep_by::<Vec<_>, _, _, _>
                 (pliron::identifier::Identifier::parser(()).skip(spaces()),
                 combine::token(',').skip(spaces())));

Similarly, if you want to use this inside combine::optional, you should use combine::attempt to ensure that no input is consumed if the parser fails.
