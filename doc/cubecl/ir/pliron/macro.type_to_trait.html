Macro type_to_trait 

Source 
macro_rules! type_to_trait {
    ($ty_name:ty, $to_trait_name:path) => { ... };
}
Expand description

Specify that a type may be casted to a dyn Trait object. Use any_to_trait for the actual cast. Example:

trait Trait {}
struct S1;
impl Trait for S1 {}
type_to_trait!(S1, Trait);

let s1: &dyn Any = &S1;
any_to_trait::<dyn Trait>(s1).expect("Expected S1 to implement Trait");

struct S2;
let s2: &dyn Any = &S2;
assert!(
    any_to_trait::<dyn Trait>(s2).is_none(),
    "S2 does not implement Trait"
);
