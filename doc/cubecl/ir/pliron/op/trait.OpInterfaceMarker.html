Trait OpInterfaceMarker

pub trait OpInterfaceMarker { }
Expand description

Marker trait for op interface trait objects.

This is auto-implemented by the #[op_interface] macro for dyn Interface objects and is used to restrict op_cast and op_impls to interface casts.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
