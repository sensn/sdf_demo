Expand description

A pass is any code that runs on the provided Operation. Typically a transformation or (nested) passes.

Transformations must not modify the IR outside of the Operation they are applied to.

If this Pass contains, manages and runs other passes, get self as a PassManager. Most passes do not qualify and must not override this method.
