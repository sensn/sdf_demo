Expand description

Cast a Box<dyn Any> object to a Box<dyn Trait> object for any trait that the contained (in Any) type implements, and for which boxed_type_to_trait has been specified.

To cast from Box<dyn Trait1> to Box<dyn Trait2> (when the underlying type implements both), the user may use downcast_rs to easily upcast from Box<dyn Trait1> to Box<dyn Any>, and then use boxed_any_to_trait to cast to Box<dyn Trait2>.

Example:


trait Trait1 {}
trait Trait2 {}

struct S;
impl Trait1 for S {}
impl Trait2 for S {}

boxed_type_to_trait!(S, Trait2);

let s1: Box<dyn Any> = Box::new(S);
boxed_any_to_trait::<dyn Trait2>(s1).expect("Expected S to implement Trait2");

struct S2;
let s2: Box<dyn Any> = Box::new(S2);
assert!(boxed_any_to_trait::<dyn Trait2>(s2).is_none(), "S2 does not implement Trait2");
