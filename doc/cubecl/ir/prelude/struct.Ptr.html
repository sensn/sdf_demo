pub fn deref(&self, ctx: &'a Context) -> Ref<'a, T>

Borrow the inner RefCell and return a Ref to the pointee. The borrow is live as long as the returned Ref lives. Panics on dangling Ptr or borrow interior mutability errors. Run cargo with options +nightly -Zbuild-std -Zbuild-std-features="debug_refcell" to enable printing the interior mutability violation locations.

Source

pub fn deref_mut(&self, ctx: &'a Context) -> RefMut<'a, T>

Mutably borrow the inner RefCell and return a RefMut to the pointee. The borrow is live as long as the returned RefMut lives. Panics on dangling Ptr or borrow interior mutability errors. Run cargo with options +nightly -Zbuild-std -Zbuild-std-features="debug_refcell" to enable printing the interior mutability violation locations.

Source

pub fn try_deref(&self, ctx: &'a Context) -> Result<Ref<'a, T>, Error>

Try and borrow the inner RefCell and return a Ref to the pointee. The borrow is live as long as the returned Ref lives. If Ptr is dangling or already mutably borrowed, an Error with DanglingPtrDerefError or BorrowError is returned.

Source

pub fn try_deref_mut(&self, ctx: &'a Context) -> Result<RefMut<'a, T>, Error>

Try and mutably borrow the inner RefCell and return a RefMut to the pointee. The borrow is live as long as the returned RefMut lives. If Ptr is dangling or already borrowed, an Error with DanglingPtrDerefError or BorrowMutError is returned.
