Trait IsolatedFromAboveInterface 

Source 
pub trait IsolatedFromAboveInterface: Op { }
Expand description

An Op whose regions’s SSA names are isolated from above. This is similar to (but not the same as) MLIR’s IsolatedFromAbove trait. Definition: all regions that are reachable / traversible in any direction in the region hierarchy without passing an IsolatedFromAbove barrier, share the same SSA name space. i.e., a region that is not IsolatedFromAbove cannot have any SSA name in common with that of any of its ancestors or siblings or cousins etc.
