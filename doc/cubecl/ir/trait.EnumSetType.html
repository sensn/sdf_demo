Expand description

An enum whose variants can be collected into an EnumSet.

Derive it with #[derive(EnumSetType)], alongside Clone, Copy, PartialEq and Eq.

The set is backed by a u64, so an enum may have at most 64 variants, and it must be a plain C-like enum with no fields.
