Expand description

Decode ue8m0 codes: a bare exponent, so the code is the f32 exponent field.

Kept apart from fp8_bits_to_f32() rather than folded into it. That one splits a byte into sign, exponent and mantissa; ue8m0 has only the exponent, spends the top bit on it, and puts its bottom code where the other formats put zero. Threading those three differences through the generic body would put a branch on every line of a function two working formats depend on.

Bits above the low byte are ignored.
