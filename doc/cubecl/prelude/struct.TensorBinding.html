Expand description

Tensor representation with a reference to the server handle, the strides and the shape.

Fields§

§handle: BufferBinding§strides: Strides§shape: Shape§tiling: Tiling

How many fragments each logical dim is stored as; untiled by default. The shape and strides stay physical, as on Metadata.
