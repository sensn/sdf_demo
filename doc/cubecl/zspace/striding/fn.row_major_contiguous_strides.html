Expand description

Construct row-major contiguous strides for a shape.

This will return a new vec strides such that:

  • rank == shape.len()
  • strides.len() == rank
  • strides[rank - 1] == 1
  • for i in 0..rank - 1 { strides[i] == strides[i + 1] * shape[i + 1] }

If rank == 0, this will return vec![].
